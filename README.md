# Interior Designer

3D interior design platform built with Vue.js and Three.js.

## Overview

Interior Designer is a web-based visualization platform that allows users to arrange furniture, customize room layouts, and preview interior design concepts in a 3D environment.

The application provides an interactive workspace for experimenting with room designs before making real-world decisions.

## Features

- 3D room visualization
- Furniture placement and arrangement
- Object movement and rotation
- Interactive design workspace
- Layout customization
- Scene export functionality
- Responsive user interface

## Tech Stack

### Frontend

- Three.js
- JavaScript
